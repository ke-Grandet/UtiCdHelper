# UtiCdHelper

一个 Windows 桌面小工具：把游戏里的技能冷却读成可管理的数字，并按**游戏内时钟**倒计时，最后把"什么时候就绪"一键生成文本发到聊天里。

核心思路是**不和现实时间对表**——游戏可以暂停、最小化、掉帧，所以倒计时跟的是屏幕上那个时钟（正计时，`mm:ss` 或 `hh:mm:ss`）。

---

## 功能

- **五个方格**：填技能的冷却秒数（0-999，可直接编辑），也可由识图自动填入，方格上方显示技能名。
- **识图**：OCR 读取屏幕上三块区域——名称（汉字）、初始值（秒数）、计时（时刻）。每块区域可单独框选、单独调参、当场测试。
- **启动计时**：以方格里的秒数为总时长，启动时读一次屏幕时钟作为基准，之后跟着时钟走；重复点击=重新开始；初始值为 0 时不启动。
- **悬浮圆点窗**：屏幕上一排五个圆点，与方格一一对应。绿色=空闲，蓝色=倒计时中并显示剩余秒数；鼠标移上去会淡出，不挡操作。
- **喊话**：把"敌方【名】技能至多在【时刻】前就绪！"（剩余为 0 时是"敌方技能已就绪！"）复制到剪贴板，直接粘贴发送。
- **快捷键**：识图、启动计时 1-5、喊话 1-5、显示/隐藏悬浮窗，均可自行改键。
- **调节位置**：悬浮窗的位置、圆点大小、圆点间距可以拖着调，也可以用方向键做像素级微调。
- **复位**：一键清零五个数字与名字，并停掉所有倒计时。

## 快速开始

### 直接用（免安装）

1. 进入 `bin/publish/Portable/`，双击 `UtiCdHelper.exe`
   （或用 `bin/publish/UtiCdHelper.bat` 启动，它会去 `Portable` 文件夹里找 exe）
   `UtiCdHelper.bat` 在仓库根目录也有一份，会按"同级 Portable"或"仓库内 bin/publish/Portable"两处找 exe
2. 第一次运行会把内置的 OCR 训练数据解压到 `%LOCALAPPDATA%\UtiCdHelper\tessdata`
3. 整个文件夹拷到任意 **Windows x64** 机器都能用——运行时已经打进文件夹里，
   目标机**不需要另外安装 .NET**。注意这是"跨机器便携"，不是"跨平台"

### 从源码构建

需要 Windows + .NET 8 SDK（`net8.0-windows`，x64）：

```powershell
dotnet build                                   # 调试构建
dotnet publish -p:PublishProfile=Portable      # 免安装目录，输出到 bin/publish/Portable
```

## 使用说明

### 1. 配置识别区域

右下角 **识图设置** → 三块区域各自"框选"并调三个参数：

| 参数 | 说明 |
| --- | --- |
| 放大 1-8 | 把截图放大几倍再交给识别。字小就调到 4-5，字够大用 1-3 |
| 阈值 -1 到 255 | 区分"字"和"背景"的亮度界线。`-1` 为自动；背景花、自动认错时试 128 或 160 |
| 反色 | 亮字配深底打开，深字配亮底关闭 |

- **初始值区域**读到的是秒数，**计时区域**读到的是时刻（`mm:ss` / `hh:mm:ss`），**名称区域**读的是汉字（用中文模型）。
- 调完点"测试"当场看识别结果，不用回到主界面。

### 2. 填初始值

- 主界面 **识图**：识别后弹出选格窗口，点一格填入（名字一并写入）。窗口先弹出、识别在后台跑，不会卡界面。
- 也可以直接在方格**里手输**数字，效果等同识图填入。

### 3. 计时与喊话

- **启动**：以方格值为总时长开始倒计时；**喊话**：把就绪时刻复制到剪贴板。
- 倒计时与屏幕时钟同步：游戏暂停、最小化时它也停。
- 顶部 **镜像悬浮窗横坐标** 勾选后，悬浮窗实际横坐标取为配置值相对屏幕中心垂线的镜像位置（仅本次运行有效，不保存）。

### 4. 调节悬浮窗

主界面右下角 **调节位置**：

| 操作 | 效果 |
| --- | --- |
| 拖动悬浮窗本体 | 移动位置 |
| Shift + 横向拖动 | 改圆点大小 |
| 在悬浮窗上滚滚轮 | 改间距（Shift 每次 5 像素） |
| 方向键 | 移动 1 像素；Ctrl + 方向键 10 像素 |
| Shift + 左右 / 上下 | 改间距 / 改大小 |

离开该界面会自动恢复鼠标穿透，悬浮窗不再挡操作。

### 5. 默认快捷键

修饰键默认都是 `Ctrl+Shift`：

| 动作 | 默认按键 |
| --- | --- |
| 识图 | Ctrl+Shift+F |
| 启动计时 1-5 | Ctrl+Shift+1 … Ctrl+Shift+5 |
| 喊话 1-5 | Ctrl+Shift+Q / W / E / R / T |

快捷键列表在**快捷键**界面里改键；条目本身（11 条：识图 1 + 启动计时 5 + 喊话 5）由默认配置文件决定，删掉某条则该条回到内置默认值。

## 配置文件

全部在 **exe 同级目录**，都是 JSON，可直接改：

| 文件 | 内容 |
| --- | --- |
| `utiCdHelper识图设置.json` | 三块识别区域的坐标与参数 |
| `utiCdHelper快捷键设置.json` | 快捷键绑定 |
| `utiCdHelper浮窗设置.json` | 悬浮窗坐标、圆点间距、圆点大小 |
| `utiCdHelper默认配置.json` | **默认配置**：首次生成用户配置、点"默认"按钮时用的初值 |

`默认配置.json` 里每一项都可空，删掉就等于"用内置值"。示例：

```json
{
  "Initial": { "X": 100, "Y": 100, "Width": 120, "Height": 48, "Scale": 3, "Threshold": -1, "Invert": false },
  "Timer":   { "X": 100, "Y": 100, "Width": 120, "Height": 48, "Scale": 3, "Threshold": -1, "Invert": false },
  "Name":    { "X": 100, "Y": 100, "Width": 160, "Height": 48, "Scale": 3, "Threshold": -1, "Invert": false },
  "Overlay": { "X": null, "Y": 0, "Spacing": 26, "Size": 26 },
  "Sampling": { "Samples": 1, "SampleDelayMs": 60 },
  "Shout": {
    "Ready": "敌方【{0}】技能已就绪！",
    "Pending": "敌方【{0}】技能至多在【{1}】前就绪！"
  },
  "FollowProcessName": "SourceTree",
  "HotKeys": [ { "Name": "识图", "Group": "识图", "Modifiers": "Control, Shift", "Key": "F" } ]
}
```

其中：

- `Overlay.X` 留 `null` 表示横向居中（默认行为取决于屏幕宽度，不适合写死）。
- **`Sampling.Samples`**：识别时连续采几帧、至少两帧一致才采纳。`1`（默认）= 关闭多帧采样，识别最快；识别区域有动画/遮挡、偶发读错时改成 `2` 或 `3` 重新启用（每多一帧多等 `SampleDelayMs` 毫秒）。
- **`Shout`**：喊话文本模板。占位符固定两个——`{0}` = 技能名（没名字就是"N楼"），`{1}` = 就绪时刻。`Ready` 用于已就绪、`Pending` 用于还在倒计时。少写占位符没事；万一写坏（比如多写一个）会自动退回内置文本，喊话功能不会失效。
- **`FollowProcessName`**：悬浮窗跟随的进程名（不带 `.exe`）。该进程有窗口时显示悬浮窗，未运行或最小化时隐藏。留空则用内置兜底值。

用户自己的三个配置文件存在时始终优先于默认配置。

## 目录结构（主要源码）

| 文件 | 职责 |
| --- | --- |
| `App.xaml.cs` | 启动装配、识图入口、悬浮窗显隐 |
| `MainWindow` / `MainView` | 主窗口与主界面（方格、启动、喊话、复位） |
| `RecognitionSettings.cs` | OCR 识别、参数、训练数据解压 |
| `ImagePreprocessor.cs` | 灰度/二值化/放大/加边框 |
| `RecognitionView` / `RecognitionAreaView` | 识图设置界面 |
| `CountdownService.cs` | 跟游戏时钟对表的倒计时核心 |
| `CountdownStarter.cs` | 启动计时与喊话 |
| `OverlayWindow` | 悬浮圆点窗（含调节模式） |
| `OverlaySettings.cs` / `OverlayPositionView` | 悬浮窗摆放参数与调节界面 |
| `HotKey*.cs` / `HotKeyView` | 快捷键注册与设置界面 |
| `DefaultsSettings.cs` | 外部默认配置文件 |
| `ProcessWatcher.cs` | 跟随指定进程显隐悬浮窗 |

## 已知限制与注意事项

- **仅 Windows x64，不支持 Linux/macOS**：界面是 WPF，全局热键、鼠标位置、窗口穿透走 `user32.dll`，截图走 GDI，OCR 用的是 `win-x64` 的原生库。要跨平台得整套换掉（WPF → Avalonia/MAUI 等），等于重写。上文的"免安装"指的是目标机不用装 .NET 运行时，不是跨平台。
- **不能打成单文件**：Tesseract 的原生库加载依赖 `Assembly.Location`，`PublishSingleFile` 下它是空串，初始化时会抛 `ArgumentNullException`。请用 `Portable` 那个发布配置。
- **配置文件写在 exe 同目录**，请把程序放在有写权限的目录（不要放 `Program Files`）。
- OCR 训练数据（`eng`、`chi_sim`）随程序内置，首次运行解压到 `%LOCALAPPDATA%\UtiCdHelper\tessdata`，约 6 MB。
- 悬浮窗的显隐跟随 `FollowProcessName` 指定的进程：该进程有窗口时显示，未运行或最小化时隐藏。
- 名称识别用的是中文模型，识别不到时保留格子原有的名字，不会清空。
